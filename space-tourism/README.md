# 🚀 Space Tourism Website

A responsive, multi-page space tourism website built with React as part of the [Frontend Mentor Space Tourism challenge](https://www.frontendmentor.io/challenges/space-tourism-multipage-website-gRWj1URZ3).

Explore destinations across the solar system, meet the crew, and discover the technology behind space travel.

## ✨ Features

- Four pages: Home, Destination, Crew, and Technology
- Responsive layouts for mobile, tablet, and desktop
- Interactive destination tabs for exploring planets
- Crew member selection with dynamically updated information
- Interactive technology selector
- Responsive navigation with a mobile menu
- Accessible interactive controls with appropriate ARIA attributes
- Custom typography, backgrounds, and layouts inspired by the original design

## 🛠️ Built With

- React
- JavaScript (ES6+)
- React Router
- Vite
- CSS3
- CSS Grid and Flexbox
- CSS custom properties
- Google Fonts
- Mobile-first responsive design

## ⚙️ Getting Started

To run the project locally, make sure you have Node.js and npm installed.

1. Clone the repository:

   ```bash
   git clone https://github.com/sylcym/frontend-mentor-challenges.git
   ```

2. Navigate to the project directory:

   ```bash
   cd frontend-mentor-challenges/space-tourism
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
